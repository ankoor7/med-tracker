# spikes/

Time-boxed investigations and research write-ups that aren't (yet) product specs.
A spike answers a question or de-risks a direction; the outcome lands here so the
decision is recoverable later. Specs in `specs/` remain the source of truth — a
spike _feeds_ them.

**Convention:** one Markdown file per investigation, named
`YYYY-MM-DD-short-slug.md`, opening with a status box and a TL;DR/outcomes table.
